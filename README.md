# Электронный журнал

Веб-приложение школьного электронного журнала: **10-балльная система оценок**,
**4 учебные четверти**, три роли — администратор, учитель, ученик.

## Возможности

**Администратор** — панель управления, статистика, создание учётных записей,
**массовый импорт учеников** (вставьте список ФИО текстом — логины и временные
пароли создадутся сами), сброс паролей, смена ролей.

**Учитель** — журнал класса (строки — ученики, столбцы — уроки), переключение
предметов и четвертей, выставление оценок кликом или с клавиатуры, управление
предметами и уроками, карточка ученика со всеми предметами сразу, экспорт в CSV.

**Ученик** — собственный дневник: таблица предметов со средними баллами за каждую
из четырёх четвертей и годовой оценкой, лента последних оценок.

## Стек

Next.js 15 (App Router) · TypeScript · Tailwind CSS · Prisma + SQLite ·
NextAuth.js v5 (Credentials + bcrypt) · Zod · Lucide Icons

## Запуск

```bash
npm install
cp .env.example .env      # и подставьте свой AUTH_SECRET
npm run setup             # prisma generate + db push + seed
npm run dev               # http://localhost:3000
```

Демо-аккаунты после `npm run setup`:

| Роль | Логин | Пароль |
|---|---|---|
| Администратор | `admin@school.com` | `admin123` |
| Учитель | `teacher@school.com` | `teacher123` |
| Ученик | `student@school.com` | `student123` |

Сид создаёт 6 учеников класса 9-А, предметы Математика / Физика / Литература
и заполненные 1 и 2 четверти.

## Как считаются оценки

- Оценка — целое число от 1 до 10.
- Средний балл за четверть — среднее арифметическое, округление до сотых (`7.45`).
- Годовая оценка — среднее средних баллов непустых четвертей, округление до целого
  1–10 (`0.5` вверх).

## Горячие клавиши в журнале

| Клавиши | Действие |
|---|---|
| `←` `→` `↑` `↓` | перемещение по ячейкам |
| `1`…`9` | выставить оценку |
| `0` или `10` | выставить 10 |
| `Enter` | открыть выбор оценки мышью |
| `Delete` / `Backspace` | удалить оценку |

После выставления оценки фокус переходит к следующему ученику — столбец
заполняется без мыши.

## Безопасность

- Пароли хранятся только как bcrypt-хеши.
- Роль проверяется на сервере в каждом Server Action и Route Handler
  (`requireRole` в `src/lib/auth-guards.ts`): ученик получает 403 и не может
  изменить ни одной оценки, даже отправив запрос в обход интерфейса.
- Оценка валидируется схемой Zod: только целое число 1–10.
- Middleware — дополнительный, а не единственный рубеж защиты.
